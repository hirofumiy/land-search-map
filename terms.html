利用規約

制定日：2026年5月21日

本利用規約（以下「本規約」）は、合同会社440（以下「当社」）が提供する蓄電所候補地マップサービス「BatteryLand」（以下「本サービス」）の利用に関する条件を定めるものです。本サービスをご利用いただく場合、本規約にご同意いただいたものとみなします。

第1条（サービス概要）

本サービスは、蓄電所・変電所の用地候補情報および関連する電力会社エリアデータを地図形式で提供するSaaS型情報サービスです。本サービスが提供する情報は参考情報であり、投資・事業判断の根拠となる確定情報ではありません。

第2条（利用登録・アカウント）

  1. 利用登録はメールアドレスおよびパスワードにより行います。
  2. 登録情報は正確・最新の情報を入力してください。虚偽・誤りのある情報での登録は禁止します。
  3. アカウントの管理はユーザー自身の責任で行うものとします。第三者へのアカウント譲渡・貸与は禁止します。
  4. 登録情報に誤りが判明した場合、当社は事前通知なく登録を取り消すことができます。
  5. 本サービスは1アカウントにつき1端末での同時利用を原則とします。複数端末からの同時ログインを検知した場合、先行セッションを強制終了することがあります。

第3条（料金・支払い）

  1. 有料プランの料金は以下のとおりです（いずれも税別）。
    • Standardプラン：月額 ¥150,000（電力会社エリア1社付属）
    • 追加エリア：¥50,000／月／社
    • 初回登録料：¥50,000（初回契約時のみ・返金不可）
    • Enterpriseプラン：月額 ¥500,000（詳細はお問い合わせください）
  2. 月額利用料の支払いはクレジットカードによる月次自動決済（Stripe）となります。
  3. 請求サイクルは契約日を起算日として1ヶ月ごとです。
  4. 料金は予告なく変更される場合があります。変更がある場合は30日前までにサービス上でお知らせします。

第4条（試用期間）

  1. 新規登録ユーザーは、初回ログインから7日間（168時間）、本サービスの全機能を無料でご利用いただける試用期間を提供します。
  2. 試用期間中はクレジットカード情報の入力は不要です。
  3. 試用期間終了後に継続してサービスをご利用いただく場合は、有料プランへのお申込みが必要です。
  4. 試用期間の延長は原則として行いません。

第5条（解約・プラン変更）

  1. サブスクリプションはいつでも解約することができます。解約後は解約月末まで引き続きご利用いただけます。
  2. プランのアップグレード・ダウングレードは翌請求サイクルより適用されます。
  3. 当社は、ユーザーが本規約に違反した場合、事前通知なくアカウントを停止・削除する権利を有します。

第6条（返金ポリシー）

  1. デジタルコンテンツの性質上、原則として支払済みの料金の返金は行いません。
  2. 月途中での解約における残日数分の日割り返金は行いません。
  3. 初回登録料は、いかなる場合においても返金いたしません。
  4. ただし、当社の責に帰すべき事由により本サービスが正常に提供できなかった場合は、個別にご相談の上、適切な対応を検討します。
  5. 試用期間内に自発的に解約した場合、料金は発生しません。

第7条（禁止事項）

ユーザーは以下の行為を行ってはなりません。

  • 本サービスのコンテンツ（地図データ・用地情報・変電所情報等）を無断で複製・転載・販売・再配布する行為
  • 本サービスへの不正アクセス、またはシステムに過度の負荷をかける行為（スクレイピング等を含む）
  • 第三者のアカウントを不正に利用する行為、またはアカウント情報を第三者に提供・共有する行為
  • 本サービスをリバースエンジニアリング・逆コンパイルする行為
  • 競合サービスの開発・改善を目的とした本サービスの利用
  • 法令または公序良俗に違反する行為
  • 当社または第三者の権利・利益を侵害する行為
  • その他当社が不適切と判断する行為

第8条（知的財産権）

  1. 本サービスに関する著作権・商標権・その他の知的財産権は、当社または正当な権利者に帰属します。
  2. 本規約はユーザーに対し、本サービスを利用する限定的な非独占的ライセンスを付与するものであり、いかなる知的財産権も移転するものではありません。
  3. 本サービスに含まれる第三者の地図データ・情報については、当該第三者の知的財産権が適用されます。

第9条（免責事項）

  1. 本サービスが提供する情報（変電所空き容量・用地候補情報・地図データ等）は参考情報であり、その正確性・完全性・最新性を保証するものではありません。
  2. 地図データは第三者が提供するデータを使用しており、当社はその精度・信頼性について一切の保証を行いません。
  3. ユーザーは自己の判断と責任において本サービスを利用するものとします。本サービスの情報に基づく投資・事業上の判断によって生じた損害について、当社は責任を負いません。
  4. 天災・サイバー攻撃・通信障害・第三者サービスの障害等、当社の合理的な管理の及ばない事由によるサービス停止・データ損失について、当社は責任を負いません。
  5. 当社の責任が認められる場合であっても、その賠償額は直近3ヶ月分のサービス利用料を上限とします。

第10条（個人情報の取り扱い）

当社は、ユーザーの個人情報を別途定める「プライバシーポリシー」に従い適切に管理します。

第11条（サービス変更・終了）

  1. 当社は、必要と判断した場合、ユーザーへの事前通知をもってサービス内容を変更することができます。
  2. 当社は、30日前の事前通知をもって本サービスを終了することができます。サービス終了の場合、終了日以降の未使用期間に相当する月額利用料を返金します。
  3. 緊急のセキュリティ上の理由等により、予告なくサービスを一時停止することがあります。

第12条（準拠法・管轄裁判所）

本規約の解釈には日本法を準拠法とし、本サービスに関して生じた紛争については、大阪地方裁判所を第一審の専属的合意管轄裁判所とします。
